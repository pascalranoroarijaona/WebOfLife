\section{Introduction \& Systems Ecology Context}
Ecosystem stability and thermodynamic efficiency rely heavily on continuous monitoring of matter and energy fluxes. Within the \emph{Web of Life} simulation architecture, metabolic pools, elemental stocks, and trophic tiers are modeled as state vectors subject to rigorous conservation laws. 

To evaluate whether a simulated ecosystem transition violates mass-balance constraints or diverges from steady-state expectations, the system requires precise discrepancy metrics. \section{Mathematical Formalization}
Let $S_A$ denote the \texttt{actual} thermodynamic state vector and $S_E$ denote the \texttt{expected} state vector. Each vector maps elemental keys $k \in K$ (e.g., \texttt{'C'}, \texttt{'N'}, \texttt{'P'}, \texttt{'H2O'}) to scalar mass or molar quantities ($\mathbb{R}_{\ge 0}$).

The total universe of keys across both records is defined as:
\[ K_{\text{total}} = \text{keys}(S_A) \cup \text{keys}(S_E) \]

For any key $k \in K_{\text{total}}$, if a key is missing from either dictionary, its default quantity evaluates to $0$. The absolute stock delta $\Delta(k)$ is formally defined as:
\[ \Delta(k) = \left| S_A(k) - S_E(k) \right| \]

The resulting delta record $\Delta_{\text{vector}}$ is constructed as:
\[ \Delta_{\text{vector}} = \{ k : \Delta(k) \mid \forall k \in K_{\text{total}} \} \]

\section{Software Architecture \& Implementation}
The implementation resides in \texttt{src/thermodynamics/state\_validator.ts}, adhering to strict functional programming principles and integrating seamlessly with existing monad validation pipelines.

\begin{lstlisting}[caption={Implementation of \texttt{computeAbsoluteStockDelta} in TypeScript}]
/**
 * Computes the absolute stock delta between actual and expected thermodynamic state vectors.
 * 
 * @param actual - Record of actual elemental stock quantities.
 * @param expected - Record of expected/baseline elemental stock quantities.
 * @returns A new record mapping each elemental key to its absolute numerical difference.
 */
export function computeAbsoluteStockDelta(
    actual: Record<string, number>,
    expected: Record<string, number>
): Record<string, number> {
    const allKeys = new Set([...Object.keys(actual), ...Object.keys(expected)]);
    const deltas: Record<string, number> = {};

    for (const key of allKeys) {
        const actualVal = actual[key] ?? 0;
        const expectedVal = expected[key] ?? 0;
        deltas[key] = Math.abs(actualVal - expectedVal);
    }

    return deltas;
}
\end{lstlisting}

\subsection{Key Architectural Properties}
\begin{enumerate}
    \item \textbf{Purity \& Immutability:} Inputs (\texttt{actual} and \texttt{expected}) are never mutated. A fresh record is returned, preserving state transition monad determinism.
    \item \textbf{Asymmetric Key Resilience:} Utilizing JavaScript \texttt{Set} unions combined with nullish coalescing (\texttt{?? 0}) ensures sparse state vectors do not trigger runtime reference exceptions.
    \item \textbf{Floating-Point Precision:} Discrepancies are computed directly in scalar space to facilitate rigorous floating-point tolerance checks ($\epsilon < 10^{-12}$).
\end{enumerate}
