\section{Introduction}
\IEEEPARstart{S}{imulating} coupled biogeochemical and hydrological dynamics across planetary biospheres requires discrete representations that preserve continuous conservation laws. The Web of Life simulation architecture employs Uber's Hierarchical Hexagonal Spatial Index (H3) to project geodesic control volumes across the terrestrial and oceanic surfaces.

In finite-volume spatial computations, control volumes maintain thermodynamic stocks: water mass $M_w$, carbon mass $M_c$, mineral mass $M_m$, oxygen mass $M_{O_2}$, and internal energy $U$. When these cells exchange fluxes across shared boundaries, associative mappings (e.g., hash maps or spatial monads) resolve topological neighbors via string representations of the underlying 64-bit integer index.

Without canonical structural invariants, string representations are vulnerable to:
\begin{enumerate}
    \item \textbf{Leading zero divergence}: 16-character representations with redundant zeros (e.g., \texttt{"08826856235fffff"}) versus canonical 15-character representations (\texttt{"8826856235fffff"}).
    \item \textbf{Case fragmentation}: Case-sensitive hash structures generating phantom uncoupled twin cells (e.g., \texttt{"8826856235FFFFF"} vs \texttt{"8826856235fffff"}).
    \item \textbf{Asymmetric routing}: Advective boundary fluxes directed toward malformed addresses disappearing from accounting pipelines, violating the First Law of Thermodynamics:
    \begin{equation}
        \sum_{i} \dot{M}_{i, \text{in}} \neq \sum_{i} \dot{M}_{i, \text{out}}
    \end{equation}
\end{enumerate}

Sprint 037 specifies and implements the canonical regular expression constant \texttt{H3\_CANONICAL\_INDEX\_PATTERN}, formalizes its mathematical foundations, and establishes the invariants governing conservative inter-cell transport.

\section{Bitfield Specification \& Mathematical Formulation}

\subsection{Bitfield Architecture}
An H3 index $i \in \mathcal{I}_{\text{H3}} \subset \mathbb{N}$ is a 64-bit unsigned bitfield ($0 \le i < 2^{64}$). Its constituent bit divisions are partitioned as detailed in Table~\ref{tab:bitfield}.

\begin{table}[htbp]
\caption{Uber H3 64-Bit Index Bitfield Layout}
\label{tab:bitfield}
\centering
\begin{tabular}{@{}llll@{}}
\toprule
Bit Range & Field Width & Description & Valid Values \\ \midrule
Bit 63 & 1 bit & Reserved & Must be \texttt{0} \\
Bits 59--62 & 4 bits & Mode & \texttt{1} (Standard Cell) \\
Bits 56--58 & 3 bits & Sub-mode & \texttt{0} (Base Hexagon) \\
Bits 52--55 & 4 bits & Resolution $r$ & $0 \le r \le 15$ \\

Bits 0--44 & 45 bits & Aperture Paths & Hierarchical octal digits \\ \bottomrule

Under the standard hexagonal cell specification, Bit 63 is strictly $0$, and Bits 59--62 evaluate to $1_{10} = 0001_2$. Combining Bits 63 through 60 yields:
\begin{equation}
    b_{63..60} = [0001]_2 = 1_{16}
\end{equation}
Because the most significant hexadecimal nibble cannot be zero, string serializations omitting the redundant 16th zero nibble comprise exactly 15 hexadecimal digits.

\subsection{Formal Language Mapping}
Let $\Sigma_{\text{hex}} = \{0,\dots,9, \text{a},\dots,\text{f}, \text{A},\dots,\text{F}\}$. The canonical serialization bijection is:
\begin{equation}
    \phi: \mathcal{I}_{\text{H3}} \to \Sigma_{\text{hex}}^{15}
\end{equation}
The accepted language $\mathcal{L}_{\text{H3}}$ is defined by the deterministic regular expression:
\begin{equation}
    \mathcal{R}_{\text{canonical}} = \texttt{/\textasciicircum[0-9a-fA-F]\{15\}\$/}
\end{equation}

\section{Thermodynamic Transport \& Stability}

\subsection{Finite Volume Governing Equations}
For cell $i \in \mathcal{L}_{\text{H3}}$ bounded by perimeter $\partial \Omega_i$ and area $A_i$, the state vector is:
\begin{equation}
    \mathbf{S}_i = \left[ M_{w, i}, M_{c, i}, M_{m, i}, M_{O_2, i}, U_i \right]^T \in \mathbb{R}_{\ge 0}^5
\end{equation}
The 2D depth-integrated horizontal advection-diffusion equation across boundary edge segment $\Gamma_{ij}$ of length $L_{ij}$ to neighbor $j \in \mathcal{N}(i)$ is:
\begin{equation}
    \frac{\partial \mathbf{S}_i}{\partial t} = \sum_{j \in \mathcal{N}(i)} \mathbf{J}_{j \to i} + \mathbf{\Sigma}_i
\end{equation}

For any scalar mass component $k$:
\begin{multline}
    J_{k, i \to j}^{\text{mass}} = L_{ij} \cdot \Big[ v_{n, ij} \left( \theta_{ij} \rho_{k, i} + (1 - \theta_{ij}) \rho_{k, j} \right) \\
    - D_k \frac{\rho_{k, j} - \rho_{k, i}}{d_{ij}} \Big]
\end{multline}
where $\theta_{ij} = 1$ if normal velocity $v_{n, ij} > 0$ and $0$ otherwise, $\rho_{k, i} = M_{k, i} / A_i$, and $d_{ij}$ is the geodesic centroid distance.

\subsection{Exact Conservation Guard}
Over timestep $\Delta t$, the pairwise transfer operator $\mathcal{T}_{i \to j}$ enforces:
\begin{equation}
    \Delta M_{k, i} = - \Delta M_{k, i \to j}, \quad \Delta M_{k, j} = + \Delta M_{k, i \to j}
\end{equation}
\begin{equation}
    \Delta M_{k, i} + \Delta M_{k, j} = 0 \iff \{i, j\} \subset \mathcal{L}_{\text{H3}}
\end{equation}
If either index fails pattern matching against $\mathcal{R}_{\text{canonical}}$, the advective transaction terminates with an unhandled exception before state mutation occurs.

\subsection{Second Law Constraint}
Entropy production rate $\dot{S}_{\text{gen}}$ during transfer must satisfy:
\begin{equation}
    \dot{S}_{\text{gen}, i \to j} = \Delta U_{i \to j} \left( \frac{1}{T_j} - \frac{1}{T_i} \right) + \sum_{k} \Delta M_{k, i \to j} \left( \frac{\mu_{k, i}}{T_i} - \frac{\mu_{k, j}}{T_j} \right) \ge 0
\end{equation}
where $\mu_{k}$ is the chemical potential of component $k$, and $T$ is temperature derived from $U / (c_v M_{\text{total}})$.

\subsection{Courant-Friedrichs-Lewy Stability}
Numerical integration stability is bounded by the CFL constraint:
\begin{equation}
    \Delta t \le C_{\text{CFL}} \cdot \min_{i \in \mathcal{L}_{\text{H3}}} \left( \frac{d_i}{\max(|v_i|, \sqrt{g h_i})} \right), \quad C_{\text{CFL}} \le 0.5
\end{equation}

\section{Implementation Details}
The TypeScript implementation enforces static type safety via nominal branding and fast runtime regex guards:

\begin{lstlisting}[caption={Canonical H3 Implementation in src/spatial/h3_grid.ts}]
export const H3_CANONICAL_INDEX_PATTERN: RegExp = 
  /^[0-9a-fA-F]{15}$/;

export function isValidH3CanonicalIndex(
  index: string
): index is CanonicalH3Index {
  if (typeof index !== 'string' || index.length !== 15) {
    return false;
  }
  return H3_CANONICAL_INDEX_PATTERN.test(index);
}

export function assertCanonicalH3Index(
  index: string
): CanonicalH3Index {
  if (!isValidH3CanonicalIndex(index)) {
    throw new RangeError(
      `Invalid H3 index: "${index}". Pattern: ` +
      `${H3_CANONICAL_INDEX_PATTERN.source}`
    );
  }
  return index.toLowerCase() as CanonicalH3Index;
}
\end{lstlisting}
