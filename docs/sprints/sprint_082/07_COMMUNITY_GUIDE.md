Welcome to the **Web of Life (Gaia)** developer community! Sprint 082 introduces the **Thermodynamic State Vector Inventory Discrepancy Evaluator Wrapper (Sub-Task A)**. ## 1. Getting Started

The repository is hosted at [https://github.com/pascalranoroarijaona/WebOfLife](https://github.com/pascalranoroarijaona/WebOfLife).

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation & Test Execution
Clone the repository and install dependencies using standard Node tooling:

```bash
git clone https://github.com/pascalranoroarijaona/WebOfLife.git
cd WebOfLife
npm install
```

To run the verification test suite for Sprint 082, execute:

```bash
npx tsx tests/sprint_082.test.ts
```

*(Note: Never use Python tools like `pip install` or `pytest`; this is a native TypeScript and Node.js codebase.)*

## 2. Architecture Overview: Sprint 082

Sprint 082 formalizes strict state vector validation via `src/thermodynamics/state_validator.ts`. The component bridges empirical or simulated runtime states with theoretical conservation expectations under absolute First and Second Law thermodynamic constraints.

### Core Interfaces & Classes
- **`IStateDiscrepancyReport`**: Immutable snapshot containing absolute and relative discrepancies, mass deltas, entropy shifts, and energy violation flags.
- **`IStateValidator`**: Contract defining `evaluateDiscrepancy(actual, expected)`.
- **`StateDiscrepancyEvaluator`**: Concrete implementation enforcing mass-energy balance thresholds ($\epsilon = 10^{-6}$).

## 3. Good First Issues & Extension Points

External contributors looking to make an impact can build upon Sprint 082 through two primary extension tracks:

### A. Building New Thermodynamic Monads (`src/thermodynamics/`)
You can implement custom metabolic or biogeochemical monads that pipe state transformations into `StateDiscrepancyEvaluator`.
1. Create a new file: `src/thermodynamics/monads/my_custom_monad.ts`
2. Implement the `ThermodynamicMonadProcess` interface.
3. Hook your monad output into a validator check:
   ```ts
   import { StateDiscrepancyEvaluator } from '../state_validator';
   const evaluator = new StateDiscrepancyEvaluator(1e-6);
   const report = evaluator.evaluateDiscrepancy(actualState, expectedState);
   if (report.energyViolationDetected) {
     console.warn('Thermodynamic breach detected!');
   }
   ```

### B. Building New WebGL Shaders (`src/render/shaders/`)
To visualize thermodynamic discrepancies (such as spatial entropy or mass imbalances across cellular grids):
1. Navigate to `src/render/shaders/`.
2. Add a fragment shader (e.g., `entropy_heatmap.frag.glsl`) that accepts discrepancy uniforms generated by Sprint 082 reports.
3. Bind the shader pipeline in the main WebGL rendering loop.
