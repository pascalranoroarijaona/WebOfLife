\begin{abstract}
Living systems exist as open thermodynamic engines operating far from thermodynamic equilibrium, sustained by continuous external energy fluxes coupled with strict internal mass conservation laws. Sprint 082 introduces Sub-Task A of the Thermodynamic State Vector Inventory Discrepancy Evaluator Wrapper within the \textit{Web of Life} (Gaia) simulation framework. This paper formalizes the theoretical conservation equations, architectural interface contracts, and concrete algorithmic implementations (\texttt{src/thermodynamics/state\_validator.ts}) designed to evaluate discrepancies between empirical runtime state vectors and theoretical thermodynamic expectations. By enforcing strict First Law (mass-energy conservation) and Second Law (entropy production bounds) constraints, our wrapper prevents computational ledger corruption and unphysical state drift across multi-species ecological simulations.
\end{abstract}

\section{Introduction and Systems Ecology Context}
Simulating complex biospheres requires absolute adherence to physical conservation laws. In computational systems ecology, rounding errors, unmodeled metabolic pathways, or numerical integration drift can lead to the spontaneous creation or destruction of matter and energy. Within the \textit{Web of Life} architecture, maintaining strict thermodynamic boundaries is paramount to modeling sustainable ecological dynamics.

Sprint 082 establishes a rigorous validation layer: the \texttt{StateDiscrepancyEvaluator}. This component acts as a deterministic auditor comparing actual runtime state vectors ($\mathbf{x}_{\text{actual}}$) against theoretical expectations ($\mathbf{x}_{\text{expected}}$) across all tracked ecological, chemical, and physical stocks.

The official repository and complete codebase are maintained at: \url{https://github.com/pascalranoroarijaona/WebOfLife}.

\section{Thermodynamic Conservation Laws \& Mathematical Framework}

\subsection{First Law: Mass and Matter Conservation}
Let $M_i$ denote the inventory stock of elemental or molecular species $i$ (e.g., carbon, nitrogen, phosphorus, water) within the system boundary. The total mass discrepancy $\Delta M_{\text{total}}$ evaluated between actual and expected state vectors is defined as:
\begin{equation}
\Delta M_{\text{total}} = \sum_{i \in \text{mass-species}} \left( x_{\text{actual}, i} - x_{\text{expected}, i} \right)
\end{equation}

A simulation integrity violation is flagged if the absolute aggregate mass delta exceeds a strict numerical tolerance $\epsilon$:
\begin{equation}
\left| \Delta M_{\text{total}} \right| > \epsilon_{\text{tolerance}}, \quad \text{where } \epsilon_{\text{tolerance}} = 10^{-6}
\end{equation}

\subsection{Energy Balance \& Violation Criteria}
For energy stocks $j$ (internal energy, chemical bond enthalpy, thermal energy), the discrepancy is given by $\Delta E_j = x_{\text{actual}, j} - x_{\text{expected}, j}$. Spontaneous generation of energy without authorized external boundary fluxes triggers an integrity fault:
\begin{equation}
\text{energyViolationDetected} = \left( \exists j \mid \Delta E_j > \epsilon_{\text{tolerance}} \right) \lor \left( \left| \Delta M_{\text{total}} \right| > \epsilon_{\text{tolerance}} \right)
\end{equation}

\subsection{Second Law: Entropy Production}
The system entropy change ($\Delta S$) is computed directly from the thermodynamic state functions of the state vectors:
\begin{equation}
\Delta S = S(\mathbf{x}_{\text{actual}}) - S(\mathbf{x}_{\text{expected}})
\end{equation}
While local metabolic work allows organisms to reduce internal entropy ($\Delta S_{\text{system}} < 0$), the validator records $\Delta S$ as an analytical metric within the discrepancy report to monitor macroscopic thermodynamic trajectories.

\subsection{Concrete Evaluator Implementation}
The concrete implementation computes absolute and relative discrepancies across all state keys, aggregating mass inventories and testing energy constraints:
\begin{lstlisting}
import { StateVector } from './state_vector';
import { IStateValidator, IStateDiscrepancyReport } from './state_validator';

export class StateDiscrepancyEvaluator implements IStateValidator {
  private tolerance: number;

  constructor(tolerance: number = 1e-6) {
    this.tolerance = tolerance;
  }

  public evaluateDiscrepancy(
    actual: StateVector,
    expected: StateVector
  ): IStateDiscrepancyReport {
    const absoluteDiscrepancy = new Map<string, number>();
    const relativeDiscrepancy = new Map<string, number>();
    
    let totalMassDelta = 0;
    let energyViolationDetected = false;
    let entropyDelta = 0;

    const actualMap = actual.toMap();
    const expectedMap = expected.toMap();
    const allKeys = new Set([...actualMap.keys(), ...expectedMap.keys()]);

    for (const key of allKeys) {
      const actVal = actualMap.get(key) ?? 0;
      const expVal = expectedMap.get(key) ?? 0;
      const delta = actVal - expVal;
      
      absoluteDiscrepancy.set(key, Math.abs(delta));
      const rel = expVal !== 0 ? Math.abs(delta / expVal) : Math.abs(delta);
      relativeDiscrepancy.set(key, rel);

      if (
        key.includes('mass') || 
        key.includes('carbon') || 
        key.includes('nitrogen') || 
        key.includes('phosphorus') || 
        key.includes('water')
      ) {
        totalMassDelta += delta;
      }

      if (key.includes('energy') && delta > this.tolerance) {
        energyViolationDetected = true;
      }
    }

    if (Math.abs(totalMassDelta) > this.tolerance) {
      energyViolationDetected = true; 
    }

    entropyDelta = actual.getEntropy() - expected.getEntropy();

    return {
      timestamp: Date.now(),
      absoluteDiscrepancy,
      relativeDiscrepancy,
      totalMassDelta,
      energyViolationDetected,
      entropyDelta
    };
  }
}
\end{lstlisting}
