\begin{abstract}
In complex ecological and thermodynamic simulations, maintaining rigorous adherence to mass conservation laws and homeostatic steady states is paramount. Sprint 073 introduces the pure, isolated helper function \texttt{computeAbsoluteStockDelta(actual, expected)} within the Web of Life simulation framework (\texttt{src/thermodynamics/state\_validator.ts}). This function computes the absolute elemental stock discrepancies between actual and expected thermodynamic state vectors across closed elemental budgets ($C, N, P, H_2O$). By formalizing state discrepancies mathematically, the system provides foundational validation support for error-correction monads and exergy dissipation tracking. Official repository: \url{https://github.com/pascalranoroarijaona/WebOfLife}.
\end{abstract}

\section{Introduction \& Thermodynamic Foundations}
The Web of Life simulation architecture models ecosystems as open thermodynamic systems bounded by material conservation and energy dissipation laws. To ensure simulation fidelity, state vectors representing biogeochemical pools must be continuously validated against expected theoretical equilibria.

\begin{itemize}
    \item \textbf{First Law (Matter Conservation):} State vector discrepancies must be tracked strictly across closed elemental budgets without spontaneous generation or destruction of mass.
    \item \textbf{Second Law (Entropy \& Dissipation):} Discrepancies quantify deviation from steady-state homeostatic equilibrium, feeding directly into dissipation and error-correction monad structures.
\end{itemize}

\section{Mathematical Formalization}
Let an elemental stock state vector be represented as a mapping from an elemental key $e \in \mathcal{E}$ to its scalar mass or molar stock $S_e \in \mathbb{R}$.

Given an actual state vector $\mathbf{S}_{\text{actual}}$ and an expected state vector $\mathbf{S}_{\text{expected}}$, the absolute stock delta for any elemental key $e$ is defined as:

$$\Delta_e = \left| S_{\text{actual}, e} - S_{\text{expected}, e} \right|$$

Where missing keys in either vector default to an absolute stock value of $0$. Total mass imbalance across the system is subsequently derived via vector norm aggregation:

$$\|\mathbf{\Delta}\|_1 = \sum_{e \in \mathcal{E}} \Delta_e$$

\section{Implementation Specification}
The helper function is implemented as a stateless, deterministic TypeScript module located in \texttt{src/thermodynamics/state\_validator.ts}:

\begin{lstlisting}[language=TypeScript, caption={Implementation of computeAbsoluteStockDelta}]
import { StateVector, ElementalKey } from './types';

/**
 * Computes the absolute elemental stock discrepancies between actual and expected thermodynamic state vectors.
 * 
 * @param actual - The measured or simulated current StateVector.
 * @param expected - The baseline or theoretical target StateVector.
 * @returns A record mapping each ElementalKey to its absolute scalar discrepancy.
 */
export function computeAbsoluteStockDelta(
  actual: StateVector,
  expected: StateVector
): Record<ElementalKey, number> {
  const result = {} as Record<ElementalKey, number>;
  
  const allKeys = new Set<ElementalKey>([
    ...(Object.keys(actual) as ElementalKey[]),
    ...(Object.keys(expected) as ElementalKey[])
  ]);

  for (const key of allKeys) {
    const actualVal = actual[key] ?? 0;
    const expectedVal = expected[key] ?? 0;
    result[key] = Math.abs(actualVal - expectedVal);
  }

  return result;
}
\end{lstlisting}
