# Sprint 044 Method Specifications: Thermodynamic State Vector Non-Negative Entropy Assertion

## 1. Physical & Thermodynamic Foundations
The Second Law of Thermodynamics dictates that the total entropy ($S$) of an isolated system can never decrease over time, and absolute entropy must be non-negative ($S \ge 0$). In the Web of Life planetary simulation engine, thermodynamic state vectors track intensive and extensive properties across biological, physical, and industrial compartments. 

To prevent simulation divergence, unphysical states (such as negative entropy generated by numerical drift or corrupted state transitions) must be intercepted before propagation. Sprint 044 implements a pure monadic validation guard: `assertNonNegativeEntropy(state)`.

### 1.1 Thermodynamic Mass/Energy/Entropy Delta Equations
Let a thermodynamic state vector $\Gamma$ be defined as:
$$\Gamma = \{U, H, S, V, T, P\}$$

Where:
- $U$: Internal Energy ($\text{J}$)
- $H$: Enthalpy ($\text{J}$)
- $S$: Entropy ($\text{J}\cdot\text{K}^{-1}$)
- $V$: Volume ($\text{m}^3$)
- $T$: Temperature ($\text{K}$)
- $P$: Pressure ($\text{Pa}$)

The validation operator $\mathcal{V}_S(\Gamma)$ is expressed as:
$$\mathcal{V}_S(\Gamma) = \begin{cases} 
\text{ok}(\Gamma) & \text{if } S \in \mathbb{R} \text{ and } S \ge 0 \\
\text{err}(\Delta_E) & \text{otherwise}
\end{cases}$$

Where error $\Delta_E$ carries diagnostic strings for the simulation logger without triggering runtime exceptions.

## 2. Executable Monad Methods (`src/thermodynamics/state_validator.ts`)

```ts
import { ThermodynamicStateVector } from './state_vector';
import { Result, ok, err } from './types';

/**
 * Pure helper function inspecting a thermodynamic state or state vector
 * to ensure that entropy (S) satisfies the Second Law constraint: S >= 0.
 * 
 * @param state ThermodynamicStateVector or state object containing entropy property
 * @returns Result<ThermodynamicStateVector | { entropy: number }, string>
 */
export function assertNonNegativeEntropy(
  state: ThermodynamicStateVector | { entropy: number }
): Result<ThermodynamicStateVector | { entropy: number }, string> {
  if (typeof state.entropy !== 'number' || isNaN(state.entropy)) {
    return err(`Invalid entropy value: expected a valid number, received ${state.entropy}`);
  }
  
  if (state.entropy < 0) {
    return err(`Second Law Violation: Entropy cannot be negative. Received S = ${state.entropy}`);
  }

  return ok(state);
}
```
