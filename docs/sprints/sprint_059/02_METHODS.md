# Sprint 059: Thermodynamic State Vector Inventory Discrepancy Evaluator Methods

## 1. Overview
This document formalizes the mathematical and algorithmic specifications for the Thermodynamic State Vector Inventory Discrepancy Evaluator (`src/thermodynamics/state_validator.ts`). The module executes strict inventory accounting to enforce the First Law of Thermodynamics (matter conservation) and monitor Second Law compliance (dissipation/entropy tracking) across all simulated biogeochemical pools (Carbon, Nitrogen, Phosphorus, Water, and Energy stocks).

## 2. Monad Process & State Transfer Equations

The evaluator operates on discrete temporal steps $t \to t + \Delta t$, consuming prior state vectors $S(t)$, current state vectors $S(t + \Delta t)$, and integrated flux accumulators $\Phi$ generated by monad thermodynamic processes (`src/thermodynamics/monad_process.ts`).

### 2.1 Stock Delta Formulations

For any given pool $i$ within the state vector:

1. **Actual State Delta ($\Delta S_{\text{actual}, i}$)**:
   $$\Delta S_{\text{actual}, i} = S_i(t + \Delta t) - S_i(t)$$

2. **Expected Flux-Derived Delta ($\Delta S_{\text{expected}, i}$)**:
   $$\Delta S_{\text{expected}, i} = \sum_{j \in \text{Inputs}_i} \Phi_{j \to i} - \sum_{k \in \text{Outputs}_i} \Phi_{i \to k}$$

3. **Absolute Discrepancy ($\epsilon_i$)**:
   $$\epsilon_i = \left| \Delta S_{\text{actual}, i} - \Delta S_{\text{expected}, i} \right|$$

4. **Tolerance Validation Condition**:
   $$\text{violated}_i = \epsilon_i > \tau$$
   where $\tau$ is the system or method-level tolerance threshold (default: $\tau = 10^{-6}$).

## 3. Executable Monad Method Specification (`StateValidator`)

Below is the formal algorithmic structure implemented in `src/thermodynamics/state_validator.ts`:

```typescript
import { StateVector } from './state_vector';

export interface DiscrepancyReport {
  timestamp: number;
  totalDiscrepancy: number;
  poolDiscrepancies: Record<string, {
    actualDelta: number;
    expectedDelta: number;
    absoluteDifference: number;
    violated: boolean;
  }>;
  withinTolerance: boolean;
}

export interface IStateValidator {
  evaluateDiscrepancy(
    previousState: StateVector,
    currentState: StateVector,
    integratedFluxes: Record<string, number>,
    tolerance?: number
  ): DiscrepancyReport;
}

export class StateValidator implements IStateValidator {
  constructor(private toleranceThreshold: number = 1e-6) {}

  public evaluateDiscrepancy(
    previousState: StateVector,
    currentState: StateVector,
    integratedFluxes: Record<string, number>,
    tolerance?: number
  ): DiscrepancyReport {
    const activeTolerance = tolerance ?? this.toleranceThreshold;
    const poolDiscrepancies: DiscrepancyReport['poolDiscrepancies'] = {};
    
    // Determine all unique pool keys across previous and current states
    const poolKeys = new Set([
      ...Object.keys(previousState.pools || {}),
      ...Object.keys(currentState.pools || {})
    ]);

    let totalDiscrepancy = 0;
    let withinTolerance = true;

    for (const poolKey of poolKeys) {
      const prevVal = previousState.pools[poolKey] ?? 0;
      const currVal = currentState.pools[poolKey] ?? 0;
      
      const actualDelta = currVal - prevVal;
      // Integrated fluxes map expected net flux or individual pool flux contributions
      const expectedDelta = integratedFluxes[poolKey] ?? 0;
      
      const absoluteDifference = Math.abs(actualDelta - expectedDelta);
      const violated = absoluteDifference > activeTolerance;

      if (violated) {
        withinTolerance = false;
      }

      totalDiscrepancy += absoluteDifference;

      poolDiscrepancies[poolKey] = {
        actualDelta,
        expectedDelta,
        absoluteDifference,
        violated
      };
    }

    return {
      timestamp: currentState.timestamp ?? Date.now(),
      totalDiscrepancy,
      poolDiscrepancies,
      withinTolerance
    };
  }
}
```

## 4. Thermodynamic Boundary Conditions & Conservation Laws

1. **First Law Enforcement**: 
   $$\sum_{i} \epsilon_i = 0 \quad (\text{within } \tau)$$
   Any systemic drift where $\sum \epsilon_i > \tau$ signifies an unmodeled matter/energy leak or unauthorized sink within the monad transition pipeline.

2. **Second Law / Dissipation Trigger**:
   When `withinTolerance === false`, the Earth Pod telemetry receives a critical diagnostic event. This forces either a localized thermodynamic correction or a simulation halt to prevent entropy inversion artifacts.
