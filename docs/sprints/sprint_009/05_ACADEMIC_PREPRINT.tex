\begin{abstract}
Macro-level biogeochemical cycling (Carbon, Nitrogen, Phosphorus, and Water) within artificial biospheres and planetary Earth pods must fundamentally obey the laws of classical and non-equilibrium thermodynamics. In Sprint 009, we establish the formal thermodynamic state vector interface (\texttt{src/thermodynamics/types.ts}) for the \textit{Web of Life} simulation engine. This module bridges macro-scale mass-energy balance with rigorous first and second law constraints. Specifically, we formalize the internal entropy generation rate ($\dot{S}_{\text{gen}}$), the exergy destruction rate ($\dot{I} = T_0 \dot{S}_{\text{gen}}$) via the Gouy-Stodola theorem, and strict boundary flux arrays. To guarantee physical validity across stochastic simulation ticks, state transitions are governed by an immutable \texttt{ThermodynamicStateMonad} that intercepts and prevents any violation of the Clausius inequality ($\dot{S}_{\text{gen}} \ge 0$).
\end{abstract}

\section{Introduction and Thermodynamic Foundations}
The \textit{Web of Life} simulation models the Earth pod as an open thermodynamic control volume receiving solar irradiance, reradiating longwave thermal radiation to deep space, and maintaining closed-loop material cycles. 

\subsection{First Law of Thermodynamics (Energy Conservation)}
The rate of change of total system internal energy ($U_{\text{sys}}$) is governed by net boundary heat transfers and work interactions:
\begin{equation}
\frac{dU_{\text{sys}}}{dt} = \sum_k \dot{Q}_k - \dot{W}_{\text{net,out}} + \sum_i \dot{m}_i h_i
\end{equation}
In our closed-material Earth pod, external mass fluxes are zero ($\sum \dot{m}_i = 0$). Energy input is driven exclusively by incoming solar irradiance ($\dot{Q}_{\text{solar}}$) balanced by planetary thermal emission ($\dot{Q}_{\text{emit}}$):
\begin{equation}
\frac{dU_{\text{sys}}}{dt} = \dot{Q}_{\text{solar}} - \dot{Q}_{\text{emit}} + \sum \dot{W}_{\text{in,net}}
\end{equation}

\subsection{Second Law of Thermodynamics (Entropy Balance)}
The entropy balance for the open thermodynamic control volume is expressed as:
\begin{equation}
\frac{dS_{\text{sys}}}{dt} = \sum_{k} \frac{\dot{Q}_k}{T_k} + \dot{S}_{\text{gen}}
\end{equation}
Isolating the internal entropy generation rate $\dot{S}_{\text{gen}}$ yields the strict non-negativity constraint mandated by the Second Law:
\begin{equation}
\dot{S}_{\text{gen}} = \frac{dS_{\text{sys}}}{dt} - \left( \frac{\dot{Q}_{\text{solar}}}{T_{\text{sun}}} - \frac{\dot{Q}_{\text{emit}}}{T_{\text{sink}}} \right) \ge 0
\end{equation}

\subsection{Gouy-Stodola Theorem and Exergy Destruction}
Thermodynamic imperfection and work potential loss (exergy destruction rate, $\dot{I}$) are linked directly to internal entropy generation via the dead-state temperature ($T_0$):
\begin{equation}
\dot{I} = T_0 \dot{S}_{\text{gen}} \ge 0
\end{equation}
where $T_0 \approx 255\text{ K}$ represents the effective radiative sink temperature of deep space.

\section{The Immutable Thermodynamic Monad}
State mutations across simulation ticks are wrapped in immutable monad structures (\texttt{ThermodynamicStateMonad}) to intercept and reject any physical violations:

\begin{verbatim}
export class ThermodynamicStateMonad {
  private constructor(private readonly state: ThermodynamicStateVector) {}

  public static initialize(initialState: ThermodynamicStateVector): ThermodynamicStateMonad {
    if (initialState.entropyGenerationRateWattsPerKelvin < 0) {
      throw new Error("Second Law Violation: Initial S_gen_dot < 0.");
    }
    return new ThermodynamicStateMonad(initialState);
  }

  public map(transitionFn: (current: ThermodynamicStateVector) => ThermodynamicStateVector): ThermodynamicStateMonad {
    const nextState = transitionFn(this.state);
    if (nextState.entropyGenerationRateWattsPerKelvin < -1e-9) {
      throw new Error("Second Law Violation: S_gen_dot < 0 detected.");
    }
    return new ThermodynamicStateMonad(nextState);
  }

  public extract(): ThermodynamicStateVector {
    return this.state;
  }
}
\end{verbatim}
