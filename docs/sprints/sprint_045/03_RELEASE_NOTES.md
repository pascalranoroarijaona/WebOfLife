## 1. Executive Summary

Sprint 045 introduces **`applyThermodynamicOverrides`**, a high-performance, in-place state mutation helper operating directly on `H3StateTensor` spatial buffers. 

In planetary and ecosystem modeling, external forcing mechanisms—such as localized volcanic outgassing, geoengineering albedo interventions, wildfire ignition fronts, and industrial greenhouse gas emissions—require targeted modifications to individual H3 spatial hexagons without triggering costly full-tensor allocations. Prior to this release, applying ad-hoc mutations posed severe risks of untracked mass/energy drift, unphysical temperature states (violating the Third Law of Thermodynamics), negative mass quantities, and monadic desynchronization.

With `applyThermodynamicOverrides`, partial cell state updates are now first-class, strictly validated, and accompanied by a detailed thermodynamic boundary ledger (`ThermodynamicOverrideReport`). This guarantees exact First Law mass-energy conservation accounting across external inputs while preserving zero-allocation stride throughput.

## 2. Key Architectural Highlights & Theoretical Foundations

### 2.1 First Law Conservation & Boundary Ledger Accounting
In an isolated planetary manifold $\Omega$, total mass $M_\Omega$ and total internal energy $U_\Omega$ are strictly conserved:
$$\frac{dM_\Omega}{dt} = 0, \quad \frac{dU_\Omega}{dt} = \dot{Q}_{\text{solar}} - \dot{Q}_{\text{rerad}}$$

Targeted state overrides represent open-boundary fluxes entering or leaving the system over discrete simulation steps $\Delta t$. `applyThermodynamicOverrides` transparently computes and audits these boundary deltas:
$$\Delta M_{\text{override}} = \sum_{i \in \text{modified}} \left( M_i^{\text{post}} - M_i^{\text{pre}} \right)$$
$$\Delta U_{\text{override}} = \sum_{i \in \text{modified}} \left( U_i^{\text{post}} - U_i^{\text{pre}} \right)$$

Any mass or energy introduced or extracted is ledgered in the returned `ThermodynamicOverrideReport`, ensuring ecosystem audit trails remain strictly closed.

### 2.2 Second and Third Law Realizability Guarantees
The helper enforces physical realization criteria on all mutating operations:
- **Matter Non-Negativity:** Mass pools ($S_{m,i} \in \{\text{water}, \text{soil organic carbon}, \text{biomass}, \text{atmospheric CO}_2, \text{mineral nitrogen}\}$) are constrained such that $S_{m,i} \ge 0$.
- **Absolute Zero Lower Bound:** Temperatures are bounded by default to cosmic background / minimum thresholds:
  $$T_i \ge T_{\text{min}} > 0\,\text{K} \quad (\text{default } T_{\text{min}} = 2.73\,\text{K})$$
- **Coupled Sensible Heat Synchronization:** When temperature $T_i$ is mutated without an explicit sensible heat value, internal energy is automatically resynchronized according to composite specific heat capacity:
  $$U_{\text{sensible}, i}^{\text{new}} = \sum_{m} \left( \text{mass}_{m,i} \cdot c_{p,m} \right) \cdot T_i^{\text{new}}$$

### 2.3 Monadic Composition via `SpatialMonad`
`SpatialMonad` pipelines seamlessly chain override operations:
```typescript
const nextMonad = spatialMonad.bind(tensor => {
  const report = applyThermodynamicOverrides(tensor, overrides, {
    strictThermodynamicBounds: true,
    recomputeSensibleHeat: true,
  });
  // Ledger can be piped to audit subsystems or event streams
  return tensor;
});
```

## 3. New Interfaces & APIs

### 3.1 Type Definitions (`src/spatial/h3_types.ts`)

```typescript
/**
 * Partial thermodynamic state representing target values or overrides
 * for a single hexagonal cell.
 */
export interface CellThermodynamicOverride {
  temperatureKelvin?: number;
  waterMassKg?: number;
  soilOrganicCarbonKg?: number;
  vegetationBiomassKg?: number;
  atmosphericCo2Kg?: number;
  mineralNitrogenKg?: number;
  sensibleHeatJoules?: number;
  albedo?: number;
}

/**
 * Map or dictionary of H3 index strings to partial override parameters.
 */
export type H3ThermodynamicOverridesMap =
  | Map<string, CellThermodynamicOverride>
  | Record<string, CellThermodynamicOverride>;

/**
 * Per-cell audit record detailing mass and energy differentials.
 */
export interface CellThermodynamicDeltaRecord {
  h3Index: string;
  cellIndex: number;
  massDeltaKg: number;
  energyDeltaJoules: number;
  overriddenFields: (keyof CellThermodynamicOverride)[];
}

/**
 * Comprehensive ledger generated by applyThermodynamicOverrides.
 */
export interface ThermodynamicOverrideReport {
  timestamp: number;
  cellCountModified: number;
  netMassDeltaKg: number;
  netEnergyDeltaJoules: number;
  cellReports: CellThermodynamicDeltaRecord[];
}

/**
 * Behavioral configuration options for applying overrides.
 */
export interface OverrideOptions {
  strictThermodynamicBounds?: boolean;
  minTemperatureKelvin?: number;
  allowMassDestruction?: boolean;
  recomputeSensibleHeat?: boolean;
}
```

### 3.2 State Tensor Extension (`src/spatial/h3_state_tensor.ts`)

```typescript
/**
 * Applies partial thermodynamic overrides across specified H3 cells within the state tensor.
 * Validates domain boundaries, updates contiguous Float64Array buffers in-place,
 * and compiles a thermodynamic conservation audit report.
 *
 * @param tensor Target H3StateTensor instance.
 * @param overrides Map or Record associating H3 cell indices to partial overrides.
 * @param options Behavioral constraints (clamping, bounds checking, sensible heat recalculation).
 * @returns ThermodynamicOverrideReport detailing mass-energy additions and state changes.
 */
export function applyThermodynamicOverrides(
  tensor: H3StateTensor,
  overrides: H3ThermodynamicOverridesMap,
  options?: OverrideOptions
): ThermodynamicOverrideReport;
```

## 5. Verification & Testing

The test suite in `tests/sprint_045.test.ts` verifies all thermodynamic, architectural, and algorithmic requirements:

- **Mass-Energy Boundary Accounting:**
  - Injected $+500\,\text{kg}$ water mass and $+120\,\text{kJ}$ thermal energy across selected H3 cells in a 100-cell grid.
  - Verified `report.netMassDeltaKg === 2500` and `report.netEnergyDeltaJoules === 600000`.
  - Confirmed unmodified cells retain exact bitwise identical state buffers.
- **Physical Boundary Enforcement:**
  - Evaluated negative biomass ($-10.0\,\text{kg}$) and sub-absolute zero temperatures ($-15.0\,\text{K}$).
  - Verified that `strictThermodynamicBounds: true` triggers `ThermodynamicDomainViolationError` and `NegativeMassForbiddenError`.
  - Verified that `strictThermodynamicBounds: false` cleanly clamps state values to $[0, \infty)$ and $[T_{\text{min}}, \infty)$ respectively.
- **Monadic Invariance:**
  - Evaluated override mutations within chained `SpatialMonad` instances, validating that monadic identity and associativity laws remain unviolated.
- **Micro-benchmarks:**
  - Applied 10,000 partial cell overrides on a large H3 grid.
  - Confirmed zero allocations in the core execution path, maintaining sub-millisecond execution times without garbage collector stalls.

## 6. Migration Guide & Usage Example

### Basic Usage

```typescript
import { H3StateTensor, applyThermodynamicOverrides } from './spatial/h3_state_tensor';
import { CellThermodynamicOverride } from './spatial/h3_types';

const tensor = new H3StateTensor(gridIndices);

// Define targeted spatial modifications
const overrides = new Map<string, CellThermodynamicOverride>([
  [
    '8828308281fffff',
    {
      temperatureKelvin: 298.15,
      waterMassKg: 12500.0,
      albedo: 0.18,
    }
  ],
  [
    '8828308283fffff',
    {
      atmosphericCo2Kg: 420.0,
      vegetationBiomassKg: 8500.0,
    }
  ],
]);

// Apply overrides with strict physical bounds
const report = applyThermodynamicOverrides(tensor, overrides, {
  strictThermodynamicBounds: true,
  recomputeSensibleHeat: true,
  minTemperatureKelvin: 2.73,
});

console.log(`Updated ${report.cellCountModified} cells.`);
console.log(`Net mass injected: ${report.netMassDeltaKg} kg`);
console.log(`Net thermal energy injected: ${report.netEnergyDeltaJoules} J`);
```

## 7. Upstream Compatibility & Deprecation Notices

- **Non-Breaking Change:** `applyThermodynamicOverrides` is an additive utility. Existing calls to `H3StateTensor` methods remain completely backwards-compatible.
- **Direct Buffer Manipulation Notice:** Direct manual writes into `tensor._buffer` are formally discouraged. Downstream systems should transition to `applyThermodynamicOverrides` to ensure audit integrity and conservation tracking.
