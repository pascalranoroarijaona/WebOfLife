\begin{abstract}
Planetary-scale ecosystems operate as non-equilibrium thermodynamic engines driven by solar irradiance and constrained by strict mass conservation laws. In this paper, we report the architectural design and mathematical formulation of Sprint 007 for the \textbf{Web of Life} simulation engine: the implementation of dedicated Biogeochemical CyclePOD instances for Carbon ($\text{C}$), Water ($\text{H}_2\text{O}$), Nitrogen ($\text{N}$), and Phosphorus ($\text{P}$). Building upon prior thermodynamic foundations, each cycle is modeled as an isolated or coupled mass-conservative reservoir network managed via an abstract base class (\texttt{BaseCycle}). We detail the governing differential equations, flux rate laws modulated by solar input vectors, and executable monad transfer methods that guarantee First Law mass conservation ($\sum M_i(t) = \sum M_i(0)$) and Second Law thermodynamic consistency across simulation steps.
\end{abstract}

\section{Introduction and Systems Ecology Context}
Understanding Earth's biosphere requires treating biogeochemical cycles not as static chemical pools, but as dynamic, open thermodynamic systems governed by energy flux and mass conservation. Within the \textbf{Web of Life} engine, Sprint 007 (\texttt{sprint\_007}) establishes the computational infrastructure (\texttt{src/cycles/}) required to simulate planetary elemental cycling.

The overarching objective is to model how energy dissipation (driven by solar input $I_{\text{solar}}$) forces matter through multi-reservoir networks while strictly obeying microscopic and macroscopic conservation laws. By encapsulating these dynamics into specialized \textbf{CyclePODs}, the simulation engine achieves modularity, mathematical rigor, and high-performance execution.

Official repository and implementation details can be accessed at: \url{https://github.com/pascalranoroarijaona/WebOfLife}.

\section{Architectural Framework and Base Cycle Specifications}
To unify disparate elemental cycles, we establish an abstract base class \texttt{BaseCycle} (\texttt{src/cycles/base\_cycle.ts}). This architecture standardizes reservoir management, mass auditing, and safe transfer operations.

Let a CyclePOD be defined by a state vector $\mathbf{M}(t) \in \mathbb{R}^n$, representing elemental mass across $n$ reservoirs. The time evolution is governed by:
\begin{equation}
\frac{d\mathbf{M}}{dt} = \mathbf{S} \mathbf{F}(\mathbf{M}, I_{\text{solar}}, \Delta t)
\end{equation}
where $\mathbf{S}$ is the stoichiometric incidence matrix and $\mathbf{F}$ is the flux vector.

\section{CyclePOD Mathematical Specifications}

\subsection{Carbon Cycle (\texttt{src/cycles/carbon.ts})}
\begin{itemize}
    \item \textbf{Reservoirs:} Atmosphere ($M_{\text{atm}}$), Terrestrial Biosphere ($M_{\text{bio}}$), Ocean Surface ($M_{\text{ocean}}$), Lithosphere ($M_{\text{lith}}$).
    \item \textbf{Fluxes:} Photosynthesis ($F_{\text{photo}} = k_{\text{photo}} M_{\text{atm}} I_{\text{solar}}$), Respiration ($F_{\text{resp}} = k_{\text{resp}} M_{\text{bio}}$), Dissolution ($F_{\text{diss}}$), Outgassing ($F_{\text{outg}}$), and Burial ($F_{\text{burial}}$).
\end{itemize}

\subsection{Water Cycle (\texttt{src/cycles/water.ts})}
\begin{itemize}
    \item \textbf{Reservoirs:} Atmospheric Vapor ($M_{\text{vap}}$), Ocean ($M_{\text{oc}}$), Groundwater ($M_{\text{gw}}$), Ice Caps ($M_{\text{ice}}$).
    \item \textbf{Fluxes:} Evaporation ($F_{\text{evap}} = k_{\text{evap}} M_{\text{oc}} I_{\text{solar}}$), Precipitation ($F_{\text{precip}}$), Runoff ($F_{\text{runoff}}$), and Melting ($F_{\text{melt}}$).
\end{itemize}

\subsection{Nitrogen Cycle (\texttt{src/cycles/nitrogen.ts})}
\begin{itemize}
    \item \textbf{Reservoirs:} Atmospheric $\text{N}_2$ ($M_{\text{n2}}$), Soil Ammonia ($M_{\text{nh3}}$), Soil Nitrate ($M_{\text{no3}}$), Biomass ($M_{\text{bio}}$).
    \item \textbf{Fluxes:} Fixation ($F_{\text{fix}} = k_{\text{fix}} M_{\text{n2}} I_{\text{solar}}$), Ammonification/Nitrification ($F_{\text{nit}}$), Assimilation ($F_{\text{assim}}$), and Denitrification ($F_{\text{denit}}$).
\end{itemize}

\subsection{Phosphorus Cycle (\texttt{src/cycles/phosphorus.ts})}
\begin{itemize}
    \item \textbf{Reservoirs:} Lithospheric Apatite ($M_{\text{apatite}}$), Soil Phosphate ($M_{\text{po4}}$), Aquatic Sediment ($M_{\text{sed}}$), Biomass ($M_{\text{bio}}$).
    \item \textbf{Fluxes:} Weathering ($F_{\text{weath}} = k_{\text{weath}} M_{\text{apatite}} I_{\text{solar}}$), Uptake ($F_{\text{uptake}}$), Litterfall ($F_{\text{litter}}$), and Lithification ($F_{\text{lith}}$).
\end{itemize}

\section{Thermodynamic Conservation Guarantees}
\begin{enumerate}
    \item \textbf{First Law Mass Conservation Audit:}
    \begin{equation}
    \left| \sum_{i} M_i(t) - \sum_{i} M_i(0) \right| \leq 10^{-6}
    \end{equation}
    \item \textbf{Non-Negative Reservoir Bounds:}
    \begin{equation}
    \text{actualTransfer} = \min(\text{getStock}(\text{from}), \max(0, \text{amount}))
    \end{equation}
\end{enumerate}
